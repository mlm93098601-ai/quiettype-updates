# QuietType

本地语音输入：说话后自动整理文字，填入当前输入框。

| 平台 | 下载应用 | 下载源代码 |
| --- | --- | --- |
| Windows | **[Windows 最新版](https://github.com/mlm93098601-ai/quiettype-updates/releases/download/windows-v0.3.0/QuietType-Windows-Setup.exe)** | [Windows 源代码](https://github.com/mlm93098601-ai/quiettype-updates/releases/download/windows-v0.3.0/QuietType-Source.zip) |
| Mac | **[Mac 最新版](https://github.com/mlm93098601-ai/quiettype-updates/releases/latest/download/QuietType.zip)** | [Mac 源代码](https://github.com/mlm93098601-ai/quiettype-updates/releases/latest/download/QuietType-Source.zip) |

- **Windows：** Windows 11，支持 x64 和 ARM64，建议 16 GB 内存。运行安装包后打开应用。
- **Mac：** Apple 芯片（M 系列），macOS 26 或更高版本。解压后打开应用，按提示授权。

首次打开需联网下载语音资源：Windows 约 9.2 GB（ARM64 约 8.0 GB），Mac 约 4.43 GB；Windows 首装请预留 30 GB、Mac 预留 16 GB 磁盘空间，下载支持续传。准备完成后可离线使用，音频和识别记录不上传。

后续在「设置 → 软件更新」更新，保留词库、记录和已下载资源。

当前 Windows 安装包未使用商业代码签名，Mac 应用尚未经过 Apple 公证，首次打开可能出现系统安全确认。
